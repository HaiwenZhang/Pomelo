## 基板をより見やすく

部品を探したり、信号を追跡したり、内層の配線を確認したり。Pomelo は、そうした作業に集中できるブラウザー上のワークスペースです。**Cadence Allegro、Altium Designer、KiCad、PADS、ODB++、Ansys HFSS 3D Layout** のファイルを読み込めます。

ファイルをドラッグして開き、必要なレイヤーを絞り込み、接続を調べられます。対応ファイルの閲覧にアカウント登録、基板ファイルのアップロード、EDA ソフトウェアのインストールは不要です。

- **設計データはローカルのまま。** 基板ファイルはブラウザー内で解析され、アップロードされません。閲覧しても元のファイルは変更されません。
- **WebGPU で細部を確認。** GPU で描画した形状、基板上の文字、ネットラベルにより、配線、パッド、ビア、銅箔領域を一つの画面で確認できます。
- **信号を追跡。** ネット名や部品番号で検索して移動し、オブジェクト、つながった配線、ネット全体、部品をハイライトできます。
- **密集した配線も見やすく。** レイヤーまたはネット別に色分けし、レイヤーを単独表示できます。表示順、銅箔の不透明度、パッドの塗りつぶし、ラベルも調整できます。
- **詳細を調査。** カーソルを合わせると概要が表示され、インスペクターでプロパティを確認できます。配線やネットの選択時には配線長も表示されます。
- **基板を広く表示。** 折りたためるパネルとコンパクトな操作ツールバーを備え、English / 简体中文 / 繁體中文 / 日本語の画面表示に対応しています。

> **開発初期段階:** 対応形式の範囲と表示精度は改善中です。Pomelo は読み取り専用のビューアーであり、基板の編集や DRC は行いません。元の EDA ツールでの検証の代わりにはなりません。形式ごとの対応範囲は以下の表を、読み込み時の診断は画面の **ファイル情報** を参照してください。

## 対応形式

以下の形式を読み込めます。対応状況はファイルのバージョンや含まれるオブジェクトによって異なり、拡張子を受け付けることが形式全体への対応を意味するわけではありません。

| ソース                               | ファイル                  | 現在の対応範囲と注意点                                                                                                                             |
| ------------------------------------ | ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Cadence Allegro / パッケージ設計** | `.brd`、`.mcm`            | 配線、円弧、パッド、ビア、銅箔、基板上の文字、対応済みのパッケージ要素。バイナリーバージョンと表示ルールの対応範囲は改善中です。                   |
| **Altium Designer**                  | `.PcbDoc`                 | バイナリー形式の一部に対応。配線、パッド、ビア、保存済みの銅箔、文字を読み込みます。残る差異は診断メッセージに表示されます。                       |
| **KiCad**                            | `.kicad_pcb`              | 配線、パッド、ビア、外形、保存済みのゾーン塗りつぶし。基板上の文字やフットプリントの図形・文字はまだ表示されず、ゾーンの再塗りつぶしも行いません。 |
| **PADS**                             | `.pcb`                    | 接続、配線、パッド、ビア、銅箔を含むバイナリー形式の一部に対応。銅箔のプレビューを確認してください。図形と文字はまだ表示されません。               |
| **ODB++**                            | `.tgz`、`.tar.gz`、`.tar` | 単一の基板レベルの step に対応。パネルの step-repeat とネガティブレイヤーには対応していません。                                                    |
| **HFSS 3D Layout**                   | `.def`                    | 対応済みの形状、レイヤー、ネット、パッドスタックを読み込みます。一部の部品変換は引き続き検証が必要です。                                           |

`.brd` の読み込みは **Cadence Allegro のバイナリーファイル**を対象としています。同じ拡張子を使うすべての EDA 形式に対応しているわけではありません。

## クイックスタート

### 必要な環境

- 開発時の標準パッケージマネージャーとスクリプト実行環境は **Bun** です。リポジトリには `bun.lock` が含まれます。
- JavaScript ツールチェーンには **Node.js 24.x** を使用します。Bun の代わりに npm も利用できます。
- **WebGPU** とハードウェアアクセラレーションを利用できるブラウザーおよびグラフィックスデバイスが必要です。現在、WebGL へのフォールバックはありません。

### ローカルで実行

```sh
git clone https://github.com/HaiwenZhang/pomelo.git
cd pomelo
bun install --frozen-lockfile
bun run dev
```

Vite が表示するローカル URL（通常は [http://127.0.0.1:5173](http://127.0.0.1:5173)）を開きます。GPU の準備ができたら、次の操作を試してください。

1. **ファイルを開く**をクリックするか、対応ファイルをワークスペースにドラッグします。
2. **レイヤー**で銅箔レイヤーを単独表示するか、**色分けモード**を**ネット**に切り替えて接続を見分けます。
3. ネット名または部品番号を検索し、移動した先でカーソルを合わせるかクリックして詳細を確認します。

npm を使う場合は、リポジトリを複製した後に次を実行します。

```sh
npm install
npm run dev
```

### 主な操作

| 操作                   | 方法                                             |
| ---------------------- | ------------------------------------------------ |
| 拡大・縮小             | マウスホイールまたはツールバーの拡大・縮小操作   |
| 移動                   | キャンバス上でドラッグ、または中ボタンでドラッグ |
| 選択・詳細表示         | 選択ツールでオブジェクトをクリック               |
| 選択ツールに切り替える | `V`                                              |
| 移動ツールに切り替える | `H`                                              |
| 基板全体を表示         | `F2` または **全体**                             |
| 選択を解除             | `Esc`                                            |
| 画面の言語を変更       | 右上の言語セレクター                             |

WebGPU を初期化できない場合は、ハードウェアアクセラレーション、およびブラウザー・OS・グラフィックスドライバーの WebGPU 対応状況を確認してください。大きなファイルの読み込みや操作は、使用できるシステムメモリーと GPU メモリーにも左右されます。

## ビルドと開発

Pomelo は **TypeScript、React、Vite、Tailwind CSS、Zustand、WebGPU / WGSL** を使用しています。形式ごとのパーサーと形状処理は React の画面から分離され、共通の基板モデルを通じて描画エンジンにデータを渡します。

```sh
bun run build       # アプリの型をチェックし、dist/ を生成
bun run preview     # 製品版ビルドをローカルで確認
bun run typecheck   # アプリとテストの型をチェック
bun run test        # Vitest のテストを実行
```

npm を使う場合は、上記の `bun run` を `npm run` に置き換えてください。Bun では `bun run test` でプロジェクトの Vitest スクリプトを実行できます。

製品版の出力は静的サイトです。`dist/` をサイトのルートから HTTPS で配信するか、ローカル確認には localhost を使用してください。WebGPU にはセキュアなコンテキストが必要です。基板を処理するバックエンドは不要です。

文字のグリフには Adobe の **[Source Han Sans SC](https://github.com/adobe-fonts/source-han-sans)** を使用し、[SIL OFL 1.1](public/fonts/source-han-sans/LICENSE.txt) ライセンスに従っています。**Pomelo Sans** は、生成したフォントサブセット用に本プロジェクトが選んだ内部フォントファミリー名です。グリフのデザインは Adobe の Source Han Sans に由来します。元のライセンスでは **Source** が予約フォント名（Reserved Font Name）として指定されています。本プロジェクトは文字セットを削減した WOFF2 サブセットを事前に生成するため、これらは改変版に該当し、OFL 第 3 条の予約名制限を受けます。そのため、生成したフォントには別のファミリー名を使用し、Adobe の著作権表示と元の OFL ライセンスを保持しています。詳細は [Web フォントと予約名に関する OFL の公式説明](https://openfontlicense.org/webfonts-and-reserved-font-names/)を参照してください。

基板上の文字と自動ラベルは共通の MSDF 描画を使用します。英字、数字、一般的な工学記号のアトラスを最初に読み込み、それ以外のグリフは、基板上の文字やネット名で使われるときに限り、256 コードポイント単位の Unicode ブロックごとに読み込みます。Web UI のフォントには可変 WOFF2 サブセットを使用し、CSS の `unicode-range` で対応範囲を指定します。完全な OTF フォントはブラウザーに配信しません。

| 場所                               | 内容                                           |
| ---------------------------------- | ---------------------------------------------- |
| [`src/app`](src/app)               | ワークスペースの構成と描画処理のライフサイクル |
| [`src/components`](src/components) | レイヤー、検索、インスペクター、表示設定       |
| [`src/lib`](src/lib)               | 形式別の読み込み処理、操作、形状処理           |
| [`src/lib/board`](src/lib/board)   | 共通の基板モデルと表示ロジック                 |
| [`src/lib/render`](src/lib/render) | WebGPU レンダラーと WGSL シェーダー            |
| [`src/i18n`](src/i18n)             | 英語、簡体字中国語、繁体字中国語、日本語の文言 |
| [`tests`](tests)                   | 解析、形状、描画、操作のテスト                 |

## 貢献

さまざまな基板をより調べやすくするために、形式の互換性、表示精度、大規模基板の性能、翻訳、文書の改善への貢献を歓迎します。

- **読み込みや表示に問題がありましたか？** 元のソフトウェアとファイルのバージョン、ブラウザー / OS / GPU、再現手順、読み込み時の診断を添えて [Issue を作成](https://github.com/HaiwenZhang/pomelo/issues)してください。共有可能な小さなサンプルや比較用のスクリーンショットも役立ちます。共有前に機密の設計情報を削除してください。
- **修正を提案しますか？** パーサーや形状処理の変更には対象を絞った回帰テストを、表示の変更にはスクリーンショットを添えてください。文書化済みの動作を変更した場合は、4 言語すべての README を更新してください。
- **Pomelo が役立ちましたか？** リポジトリに Star を付けたり、PCB を調べる人に紹介したりしてください。実際の使用感は、今後の対応範囲を決める助けになります。
